# Responsive-Dashboard-

A clean, responsive admin dashboard with dark/light mode toggle built with pure HTML, CSS, and JavaScript (no frameworks).

## ✨ Features

- **Fully responsive sidebar** with collapsible submenus
- **Dark/light mode** with system preference detection
- **Animated user dropdown** in top navigation
- **Mobile-friendly** hamburger menu
- **CSS variables** for easy theming
- **No frameworks** - pure vanilla JavaScript
